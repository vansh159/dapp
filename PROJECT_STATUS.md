## 📋 **PROJECT OVERVIEW**

### **System Description**
A complete end-to-end blockchain-based supply chain management system that enables transparent tracking of agricultural products from farm to table. The system provides role-based access for different stakeholders (Farmers, Distributors, Retailers, Consumers) and ensures immutable record-keeping through smart contracts.

### **Technology Stack**
- **Blockchain**: Ethereum (Solidity Smart Contracts)
- **Backend**: Node.js + Express.js + MongoDB
- **Frontend**: React.js + Vite + Tailwind CSS
- **Web3 Integration**: Ethers.js
- **Storage**: IPFS for decentralized file storage
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT-based authentication
- **Testing**: Hardhat + Jest + Supertest
- **Deployment**: Docker + Docker Compose
